      使用說明與範例

      這個工具在做什麼

      把每個詞或句子變成一組數字（向量），再壓縮成 3D 座標畫出來。意思越接近的，在空間裡離得越近。你可以旋轉、縮放、點選，並對向量做加減運算。

      30 秒快速開始（用內建範例）

      1. 用滑鼠拖曳畫面旋轉，滾輪縮放。
      2. 點一個點（例如「貓」），右邊會列出它的最近鄰與相似度，畫面上會連線。
      3. 在右上「搜尋」輸入「蘋果」，相關的點會被標出，其他變淡。按 Esc 清空。
      4. 左邊「顏色依」切到「我的分組」，看自己的分類和模型自動分群是否一致。
      5. 往下看「詞向量運算」，點一個範例按鈕。

      看懂畫面

      • 一個點＝一筆資料（詞或句子）。距離＝語意相近程度。顏色＝分群或你的分組。
      • X／Y／Z 軸沒有語意，只是降維後的方向，不要解讀成「X 代表什麼」。
      • PCA 保留整體方向，比例較可信；t-SNE 讓近的更聚、群更分開，但遠近比例不可靠，只適合看「誰跟誰同一群」。
      • 3D 只是 384 維的投影，所以兩個點在畫面上看起來近，不一定真的近；最近鄰的相似度數字才是依據。

      詞向量運算（A − B + C）怎麼玩

      king − man + woman：減掉「男性」方向、加上「女性」方向，得到「女性的君主」，找最接近的詞。這個「方向」不是人寫的，是模型讀大量文字後自己學到的。

      最重要的一件事：先問「答案是不是本來就在 C 旁邊？」運算結果下方會顯示：這個答案原本是 C 的第幾近鄰。 如果本來就是第 1 名，運算等於沒做事，只是看起來成功。只有答案「原本排得很後面、運算後才升到第 1」，才表示加減真的帶來了新資訊。

      建議這樣做實驗：

      1. 對照：先搜尋或點選 C，記下它的最近鄰；再做運算，看答案的排名怎麼變。
      2. 換 C：保持 king − man，把 C 換成不同的詞，看結果是否跟著 C 的類別走。
      3. 看排名升了多少，不要只看分數：分數高不代表運算有效，因為近義詞本來分數就高。
      4. 做一組沒意義的：結果通常只會退回 C 的近義詞（例如下面的 貓 − 老師 + 汽車 會得到 轎車），用來分辨規律和硬湊。

        輸入你自己的資料

        • 左邊文字框每行一筆；行尾加「半形逗號＋分組」（逗號後面不要有空格）或 Tab 再加分組，可上色，例如 貓,動物。全形逗號「，」和英文句子裡的「, 」不會被當成分組。# 開頭是註解，空行會略過。
        • 檔案請存成 UTF-8。每行超過 300 字會被截斷；語意模型實際只讀每筆的前 128 個 token。
        • 也可按「選擇檔案」或把 .txt、.csv、.md 拖進來。.json 是本工具匯出的結果，載入後不必重算。
        • 計算位置有兩種（左邊「計算位置」切換）：
          • 瀏覽器內：任何方式開啟都能用（雙擊 viewer.html、GitHub Pages 皆可），資料不會離開你的電腦。第一次需連網下載函式庫與約 118 MB 的模型，之後瀏覽器會快取。限制：只有語意模型、只有 PCA、上限 1500 筆；向量因量化與本機版略有誤差（實測同一批文字餘弦相似度 0.991–0.998）。
          • 本機 Python：需先雙擊「啟動.bat」，再用 http://127.0.0.1:8765/ 開啟。用你電腦的 GPU，較快，可選 GPT-2 嵌入層與 t-SNE，上限 3000 筆。第一次要下載模型（語意模型約 470 MB、GPT-2 約 500 MB）。
        • 超過 1500 筆時 t-SNE 停用，只提供 PCA。
        • 向量來源：「語意模型」中英文都可，意思近的會靠近；「GPT-2 嵌入層」只是詞表查表（沒有上下文），中文效果差，適合拿來對照課堂講的輸入嵌入層。
